Start

A .sb file compiles to JavaScript. Node 22+ is required.

Compiler

The compiler is bin/sbc.js.

# compile a file to file.js
node bin/sbc.js beannacht.sb

# compile every .sb file under a directory
node bin/sbc.js feidhmchlár

# compile and run, awaiting príomh() if it exists
node bin/sbc.js beannacht.sb --rith

# print the generated JavaScript, don't write it
node bin/sbc.js beannacht.sb --amharc

# print every grammatical form of each top-level binding
node bin/sbc.js beannacht.sb --paraidím

# print the AST
node bin/sbc.js beannacht.sb --crann

# print the module dependency graph
node bin/sbc.js beannacht.sb --graf

A first program

struchtúr Duine {
    ainm: Teaghrán
    aois: Uimhir
}

feidhm beannacht(duine: Duine) -> Teaghrán {
    "Dia duit, " + ainm ó dhuine
}

duine seasmhach = Duine { ainm: "Charlotte", aois: 20 }

scríobh beannacht(duine)

prints Dia duit, Charlotte

Comments and entry point

// to end of line, or /* ... */.

A file's top level is a sequence of commands. If it declares an async action named príomh, --rith and the module runner will call and await it. Anything needing tar éis belongs inside príomh, not at the top level.

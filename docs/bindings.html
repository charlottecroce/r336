Bindings & Types

seasmhach / sealadach

seasmhach x = 5              // immutable
sealadach y = 5              // mutable
seasmhach x: Uimhir = 5      // explicit type

A binding must be declared in its base (unlenited) form - seasmhach dhuine = 3 is E107. Only a sealadach binding, or a sealadach parameter, may be mutated.

Mutation

cuir <luach> ar <sprioc>
sealadach comhaireamh = 0
cuir comhaireamh + 1 ar chomhaireamh

cuir is a command: only valid inside a gníomh (E502 inside a feidhm). The target must be sealadach (E510 otherwise). The target's head word lenites, the same as after ó.

Bindings & Types

seasmhach / sealadach

x seasmhach = 5              // immutable
y sealadach = 5              // mutable
x seasmhach: Uimhir = 5      // explicit type

The adjective follows its noun. An attributive adjective follows in Irish - fear mór, not mór fear - and seasmhach and sealadach are attributive adjectives. Before 0.11 the language wrote them first, which was English order in Irish words.

A binding must be declared in its base (unlenited) form - dhuine seasmhach = 3 is E107. Only a sealadach binding, or a sealadach parameter, may be mutated.

Gender

Irish nouns are masculine or feminine, the gender is largely arbitrary, and in the nominative it shows as lenition of a following adjective: fear mór but bean mhór. R336's identifiers are Irish nouns, so they have gender too.

duine seasmhach = Duine { ainm: "Cáit" }     // masculine
aois sheasmhach = Aois { luach: 20 }         // feminine
tuairisc shealadach: Teaghrán = ""           // feminine

There is no gender keyword and no new syntax. Every binding already carried an adjective and an adjective already agrees, so the form of that adjective is the declaration. Nothing is inferred from the shape of the word: the ending rules are real but say nothing at all about the fifth of Irish nouns that end in a vowel, duine among them.

One gender per noun per module. A word does not change gender between two sentences of the same text, so a second, different spelling is E527 and the message names the line where the word was first spelled. A parameter with no adjective declares nothing; it takes whatever the module already recorded, or masculine.

Agreement calls the same foirmDe that ó, ar, a and as route through, so an adjective that cannot bear a séimhiú is not an exception: aois óg and aois luath are correct after a feminine noun for the same reason ó áit is correct after a leniting preposition.

Gender carries no meaning. It never reaches E201 - two types differing only in gender are the same type - and it never survives into the emitted JavaScript.

r336c comhad.r336 --paraidím

  lemma          inscne  aidiacht     … (type, forms, source elided)
  duine          fir     seasmhach    …
  aois           bain    sheasmhach   …
  x              fir*    seasmhach    …

  * gender defaulted: there was no adjective slot to state it in

--paraidím --json gives the whole structured record. tools/imirce-inscne.js migrates pre-0.11 source: it moves the adjective, leaves comments alone, and writes every noun as masculine - it does not guess.

Mutation

cuir <luach> ar <sprioc>
comhaireamh sealadach = 0
cuir comhaireamh + 1 ar chomhaireamh

cuir is a command: only valid inside a gníomh (E502 inside a feidhm). The target must be sealadach (E510 otherwise). The target's head word lenites, the same as after ó.

A type's gender

A type name is an ordinary Irish noun, but nothing in the language puts an adjective after one, so if you want its gender recorded you state it - with an adjective, which then agrees with the noun it is declaring.

struchtúr Duine firinscneach as Corcaigh { … }
struchtúr Aois bhaininscneach { … }

suim Aimsiú bhaininscneach as Gaillimh {
    Aimsithe firinscneach { duine: Duine }
    Uireasa bhaininscneach { }
}

So the declaration checks itself. Aois baininscneach says "feminine" in the masculine form and is E526; so is Duine fhirinscneach.

It is optional. Nothing in the language yet demands agreement with a type's gender, and requiring it would collect ceremony against a rule that does not exist. Where absent, the type is masculine and --paraidím marks it as defaulted rather than declared.

Verbs

Declaring

feidhm dúbail(x: Uimhir) -> Uimhir { x + x }

gníomh scríobhLine(t: Teaghrán) { scríobh t }

saor liostaigh(mír: Teaghrán) { scríobh "· " + mír }

A gníomh or saor cannot declare a return type (E404). Inside a feidhm body the last expression statement is the return value; every other value must actually be used, not dropped (E503). A gníomh cannot be called from inside a feidhm (E502).

A parameter may carry sealadach to say the callee may change what the caller passed. Like every attributive adjective, it follows its noun and agrees with it:

gníomh taisc(cuntas sealadach: Cuntas, méid: Uimhir) { … }

Calling

A command takes no parentheses, arguments separated by commas:

scríobhLine "hello"
fógair "a", 1

A function call takes parentheses:

dúbail(21)

A gníomh can only ever be obeyed as a command, never mentioned as a value - writing its bare name, or calling it with parentheses, is E501.

A saor verb is the mirror image: it can only ever be mentioned, never commanded (E518). The autonomous states that an action happens while making its agent unnameable, so nothing inside the language can be told to perform one. In a statement you write the autonomous form, which the compiler conjugates - liostaigh → liostaítear, fógair → fógraítear. The past forms are computed and refused by name (E519): the language has no tense.

Methods

feidhm beannacht ó Dhuine(féin) -> Teaghrán {
    "Dia duit, " + ainm ó fhéin
}

scríobh beannacht ó dhuine()

ó <Cineál> after the verb name attaches it to a structure type; the type name lenites. The receiver is the first parameter, written bare with no : type. Only structures can carry methods (E509). At the call site it is the ordinary field-access relation, followed by a call: beannacht ó dhuine().

A saor verb takes no receiver (E520): féin is an agent, and the autonomous has none.

Adverse state: -> T ar A

Irish has no verb to fail. Misfortune is put on you - tá tinneas cinn orm, theip orm - and ar is the preposition that does it. A verb may declare what can happen to its result.

struchtúr Earráid { cúis: Teaghrán }

feidhm roinn(uachtar: Uimhir, íochtar: Uimhir) -> Uimhir ar Earráid {
    má íochtar == 0 {
        Earráid { cúis: "ní roinntear ar nialas" }
    } mura {
        uachtar / íochtar
    }
}

Introduction is free widening, as a sum variant widens to its sum: inside such a verb a bare Uimhir and a bare Earráid are both acceptable results, and the two má branches meet at the afflicted type. There is no constructor to write.

T ar A is a type reference, so it may be written anywhere a type is written. A must be a declared structure, sum or variant (E525) - a misfortune is a thing with a reason, and a bare Uimhir is not one. An ar clause on a gníomh or saor is E522: there is no result to afflict.

Ask with bí, whose form agrees with the governing particle exactly as it always has:

gníomh luaigh(uachtar: Uimhir, íochtar: Uimhir) {
    toradh seasmhach = roinn(uachtar, íochtar)
    má tá Earráid ar thoradh {
        scríobh "theip air: " + cúis ó thoradh   // toradh : Earráid
    } mura {
        scríobh toradh                           // toradh : Uimhir
    }
}

Both branches narrow, because an affliction is binary. Only a seasmhach binding narrows: a sealadach one can be assigned inside the branch, and a narrowing a cuir can invalidate was never true.

Until the affliction is ruled out the value is not its result type - E523 at every site that wants the plain type. Asking about an affliction no verb declared is E524, refused rather than answered bréagach, because the declaration is what creates the question. This is protective only where the verb declared it: unlike a sum, the caller is not asked to enumerate every case, only to rule out the one thing the signature named.

An adverse type is an ordinary structure, so it claims a province like any other placed type - a program that has spent all four cannot have one. Nothing survives into the emitted JavaScript: tá Earráid ar thoradh becomes __is(toradh, "Earráid"), the tag the copula already read.

Passing a verb as a value

déan a fhógair ar dhaoine
forEach ó liosta(a fhógair)

a + the lenited verb name turns a declared verb into a nominal so it can be passed where a value is expected. a before anything that is not a verb is E513 - there is no possessive determiner in the language.

A saor verb may be named this way but matches no gníomh or feidhm parameter, because anything that could accept it could call it, and calling is commanding. Its only destination is Iasacht - the boundary, which is what makes it the right mood for a route handler someone else invokes.

Verb types

feidhm(Uimhir) -> Uimhir      // indicative, one Uimhir param
gníomh(Teaghrán)              // imperative, no result
saor(Teaghrán)                // autonomous, no agent
ag feidhm(Iasacht) -> Bool    // async, see Async

Mood and aspect are part of the type: a gníomh value never matches a feidhm parameter. Used to type higher-order parameters:

gníomh faoiDhó(g: gníomh(Teaghrán), xs: Liosta(Teaghrán)) {
    déan g ar xs
    déan g ar xs
}

Iterating: déan … ar …

déan a fhógair ar dhaoine

Runs a gníomh(T) once per element of a Liosta(T) or Iasacht. The element type must match the verb's parameter (E201). déan and cuir are the two built-in verbs that take an ar phrase; a user-declared verb never takes one, so writing fógair 1 ar 2 is E515, and calling déan without the phrase is E514.

The ar of an adverse clause is a third use of the same preposition and needs no new government: it lenites what follows it through the one function every operator routes through.

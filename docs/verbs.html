Verbs

Declaring

feidhm dúbail(x: Uimhir) -> Uimhir { x + x }

gníomh scríobhLine(t: Teaghrán) { scríobh t }

A gníomh cannot declare a return type (E404). Inside a feidhm body the last expression statement is the return value; every other value must actually be used, not dropped (E503). A gníomh cannot be called from inside a feidhm (E502).

Calling

A command takes no parentheses, arguments separated by commas:

scríobhLine "hello"
fógair "a", 1

A function call takes parentheses:

dúbail(21)

A gníomh can only ever be obeyed as a command, never mentioned as a value - writing its bare name, or calling it with parentheses, is E501.

Methods

feidhm beannacht ó Dhuine(féin) -> Teaghrán {
    "Dia duit, " + ainm ó fhéin
}

scríobh beannacht ó dhuine()

ó <Cineál> after the verb name attaches it to a structure type; the type name lenites. The receiver is the first parameter, written bare with no : type. Only structures can carry methods (E509). At the call site it is the ordinary field-access relation, followed by a call: beannacht ó dhuine().

Passing a verb as a value

déan a fhógair ar dhaoine
forEach ó liosta(a fhógair)

a + the lenited verb name turns a declared verb into a nominal so it can be passed where a value is expected.

Verb types

feidhm(Uimhir) -> Uimhir      // indicative, one Uimhir param
gníomh(Teaghrán)              // imperative, no result
ag feidhm(Iasacht) -> Bool    // async, see Async

Mood and aspect are part of the type: a gníomh value never matches a feidhm parameter. Used to type higher-order parameters:

gníomh faoiDhó(g: gníomh(Teaghrán), xs: Liosta(Teaghrán)) {
    déan g ar xs
    déan g ar xs
}

Iterating: déan … ar …

déan a fhógair ar dhaoine

Runs a gníomh(T) once per element of a Liosta(T) or Iasacht. The element type must match the verb's parameter (E201). déan and cuir are the two built-in verbs that take an ar phrase; a user-declared verb never takes one, so writing fógair 1 ar 2 is E515, and calling déan without the phrase is E514.

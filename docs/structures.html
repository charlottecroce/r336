Structures

Records with typed, all-required fields.

Declaration

struchtúr Duine {
    ainm: Teaghrán
    aois: Uimhir
}

The name and every field name must be in base form (E107).

Modifiers name, adjective, marker, provenance

Three things may sit between the name and the body, and they sit in one order:

struchtúr Duine firinscneach stór as Corcaigh {
    ainm: Teaghrán
    aois: Uimhir
}
SlotWhat it is
firinscneach / baininscneach Gender. An adjective, so it goes next to its noun and agrees with it. Optional; masculine by default. See Bindings.
stór This type has a table. Not Irish grammar - an engineering marker, which is why it sits outside the grammatical material. Optional.
as <contae> Provenance. Optional; exile by default. See Counties.

Any other order is E401. The language has one order and the parser says so rather than accepting several.

stór is not a reserved word. It is read as a marker in this one slot and is an ordinary name everywhere else, so stór seasmhach = … still binds a variable called stór.

Literal

duine seasmhach = Duine { ainm: "Cáit", aois: 20 }

Every field must be given (E204 if any are missing), and only declared fields are accepted (E203).

Field access

ainm ó dhuine
baile ó sheoladh ó dhuine

<réimse> ó <luach> reads a field - right to left, like possession. The value to the right of ó lenites; the chain reads inside out, each ó governing only its own complement. See Grammar.

Tables stór

A structure marked stór has a table behind it, and its rows can be read as values of that type rather than as Iasacht. Reading is in Verbs, under faigh.

A table needs a county. Exile is not a place, so stór on a type with no as clause is E610.

And it claims only that county, where an ordinary placed type claims its whole province:

ClaimTakesSlots
ordinary struchtúr / suima province4
stór struchtúra county32

A type is the vocabulary of a region. A table is a building in one town. It is a smaller thing, so it claims a smaller place.

The two claims collide, in both directions. A table in Corcaigh stops any ordinary type claiming An Mhumhain, and an ordinary type in An Mhumhain stops a table anywhere in Munster - both E603. Two tables in the same county are E612. So the marker is not a way around the province rule; it changes the shape of the claim, not whether one is made.

32 is a ceiling, not a budget. Only a program with no ordinary placed types at all can reach it. One ordinary type costs a whole province's worth of counties.

Two tables may sit in rival counties - and then no file anywhere in the program can read both. From one of the two it is E609, which no treaty lifts; from anywhere else it is E601, and no file can hold a treaty with both. See Counties.

The table is named after the type, lowercased. Duine reads from duine. It is never pluralised: duine → daoine is suppletive, no rule reaches it, and a compiler that guessed would be confidently wrong on the first word anyone tried. The columns are the declared fields, in declaration order, and there is nowhere else to write them.

There is no stór slot on a suim, and none is coming. A sum does not enumerate rows - the same reason a method cannot be declared on one (E509).

Read-only. There is no way to write a row, generate a schema, or filter a read.

Methods

A function can be attached to a structure. See Verbs for how to declare and call one.

Modules

Importing

foclóir seasmhach = ó "./foclóir.r336"   // native R336 module
e seasmhach       = ó "express"        // npm package
p seasmhach       = ó "node:path"      // node builtin

A relative specifier resolves relative to the importing file, as in Node. A .r336 path is a native module; anything else is foreign.

Native (.r336) modules

scríobh BEANNACHT ó fhoclóir
scríobh beannaigh ó fhoclóir("Oisín")
fáiltigh "Aoife"

Values and functions are reached through the ordinary <ball> ó <modúl> relation, lenited like any other field access, with real types, mood and aspect preserved across the boundary.

An imported gníomh joins the caller's vocabulary directly and is called unqualified, like any other command - it cannot be called with a possessor, since a command is not a noun phrase: fáiltigh ó fhoclóir("Cáit") is E516.

Foreign modules

R seasmhach = Router ó "express"

Everything reached from a non-.r336 origin is Iasacht. A foreign member keeps its exact borrowed spelling - it is never lenited, and its category is only known by asking is at runtime.

Async

ag marks a verb as ongoing; tar éis completes it.

Declaring

ag feidhm oscail(conair: Teaghrán) -> Iasacht {
    tar éis stórlann.oscail(conair)
}

ag gníomh sábháil(u: Uimhir) {
    tar éis moill(u)
}

ag before feidhm or gníomh marks the verb as ongoing - it compiles to an async function.

tar éis

seasmhach stór = tar éis oscail(":memory:")

tar éis <glao> completes an ongoing call and yields its result - it compiles to await. Rules:

  • tar éis is only valid inside a verb itself marked ag (E504 otherwise).
  • The result of calling an ag verb is not a value until completed with tar éis (E505 if used directly).
  • tar éis on something that isn't an ongoing action is E508.

Ongoing commands

ag gníomh a(x: Iasacht) { tar éis x() }
ag gníomh b(x: Iasacht) { a x }   // implicitly awaited

Calling an ag gníomh as a command completes it automatically - but the calling verb must itself be ag (E504 otherwise). The same applies to déan <a-verb> ar <xs> when the verb passed in is ongoing.

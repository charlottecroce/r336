Provenance 6xx

The county and province system. A county is a lock on the box, not a border on the road: only reading a member through ó is checked.

CodeMeaning

E603That province is already claimed by another placed type. There are four slots.
E604The module declared as twice. A text is not from two places.
E605Exile cannot be declared or treatied with. It is not a place, it is what is there when no place is named.
E606A treaty with itself.
E607Duplicate treaty. A treaty holds from both sides, so the second declaration is a repetition.

The corpus

Every code above has a file in examples/earraidi/ that fails with that code and no other. test/earraidi.js checks the rule in both directions: a case that fails with the wrong code is an error, and so is a code with no case. Reserved codes must have no file — if one acquires a case, the reservation was wrong.

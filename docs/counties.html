Counties

A closed system of 32 counties and 4 provinces that controls which files may open which types.

Declaring provenance

as Corcaigh                          // once per file, at the top
struchtúr Duine as Corcaigh { … }    // once per struct or suim

A file that never writes as defaults to deoraíocht (exile). Declaring it twice in one file is E604. as demands the base form of its complement through the same government machinery as ó/ar/a - as Chorcaigh is E103 with nothing special-cased for as at all. Multi-word names (Dún na nGall, Baile Átha Cliath) are read greedily against a fixed table; a name that isn't one of the 32 is E602.

Provinces are the actual limit

32 counties, 4 provinces: Laighin, An Mhumhain, Connachta, Ulaidh. A struct or sum claims its province, not just its county - struchtúr Duine as Corcaigh closes every other county of An Mhumhain (Ciarraí, Luimneach, An Clár, Port Láirge, Tiobraid Árann) to any other placed type, for the rest of the module graph. One struct-or-sum per province, globally. A second type trying to place in an already-claimed province is E603, naming the province, the county sitting in it, and the type that put it there. The claim travels with import - an imported type's province is spent everywhere it's visible, not just in the file that declared it.

Exile

deoraíocht is what a value is from when nothing declared a home: every primitive, Iasacht, and any struct or sum with no as. It isn't a county and can't be written - as deoraíocht is E605 - it's the default rather than a destination.

Exile is deliberately asymmetric to a real county: it's non-exclusive (any number of undeclared types coexist - the alternative caps a program at four struct types, total), it can't sign a treaty (an agreement needs two parties and exile isn't one), and it's nobody's rival. Two exiled things trading with each other isn't a border crossing at all, which is why every program written before this feature existed still compiles unchanged.

The border: what ó checks

Construction, arguments, and returns all cross freely - a county is a lock on the box, not a border on the road. Only reading a field or member through ó is checked, and it's checked against the accessing file's own county, not the value's - so a struct can be built in one file and only opened in another that's allowed to.

Four cases, one comparison, because two things from nowhere are still the same nowhere:

CaseResult
same provinceallowed
different province, treaty in forceallowed
different province, no treatyE601
either side in exileallowed

Each ó in a chain (ainm ó sheoladh ó dhuine) is checked independently against its own complement, the same way each one governs its own lenition.

Treaties

comhaontú Corcaigh Gaillimh

A bilateral agreement, in force for the whole file regardless of where it's written - a treaty at the bottom licenses an access at the top. Symmetric: comhaontú A B and comhaontú B A name the same treaty, and the second writing is E607. Not transitive - Corcaigh–Gaillimh plus Gaillimh–Aontroim does not give Corcaigh–Aontroim; a transitive treaty would silently partition the 32 into blocs, which is the thing a treaty exists instead of.

File-scoped: a treaty doesn't travel in a module's exported signature, because it's a property of a place and a file is a place, not a value. A treaty with yourself is E606; naming exile is already refused by E605 before it gets here.

Rivalries: the one thing no treaty fixes

A short fixed list of traditional rivalries - Corcaigh/Ciarraí, Baile Átha Cliath/An Mhí, and a handful more, within provinces and across them - sits above the border rule rather than inside it. No treaty between rivals can ever exist (E608), and the veto overrides even same-province access that would otherwise be free (E609): a file from Ciarraí can never open a type placed in Corcaigh, treaty or not, province or not.

Exile has no history and is nobody's rival, so the veto never fires when either side is exiled. The only way out is choosing a different county - and therefore a different province - to be from; every pair of provinces keeps at least one legal county pairing, so a rivalry costs you the county you wanted, not the ability to reach a province at all.

Why this exists

as itself is ordinary Irish grammar - the preposition of provenance and belonging, is as Corcaigh mé - and it's governed by the same machinery as everything else in the language. The specific list of 32 names, the four-way grouping, and the rivalry table are not a grammatical phenomenon; they're a deliberately strange feature, then enforced with the same rigor as everything grounded in real grammar. See the Developer Guide for where this fits against the rest of the design.

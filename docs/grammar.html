Grammar

Lenition

Three operators demand the lenited (séimhithe) form of the word immediately after them:

OperatorLenitesExample
óits complement's head wordó dhuine
arits complement's head wordcuir x ar dhuine
athe verb that followsa fhógair

Only these nine consonants can lenite: b c d f g m p s t (written by prefixing h: duine > dhuine, case preserved: Duine > Dhuine). Vowels and l n r h never lenite, so the base form is written unchanged after any of the three operators above. s lenites before a vowel or l n r, but resists it in sc- sf- sm- sp- st- clusters.

A word that cannot lenite keeps its base form after ó / ar / a - that is not an exception, it is what happens when there is nothing to change. Writing a lenited form where none is called for is E103; writing the base form where lenition is required is E102; lenited spelling of a word that cannot lenite is E104.

A member borrowed from outside R336 (anything reached through ó "some-package" or ó "file.js") keeps its exact spelling and is never lenited - see Modules.

Classification: is

má aois is Uimhir { scríobh "uimhir í" }

x is Cineál asks whether x belongs to a type. The right side must be a known type name (E202), never an expression (E301). NaN belongs to no numeric category, so x is Uimhir is false for it.

Existence: tá / bhfuil

má tá duine { scríobh "ann" }
mura bhfuil duine { scríobh "as" }

bí asks whether something is present (not neamhní). Its written form must agree with the particle governing the clause: tá after má, bhfuil after mura. The wrong form is E512. bí itself is the citation / imperative form.

má / mura

má u == 1 { "a" } mura u == 2 { "b" } mura { "c" }

mura <coinníoll> means "if not", not "else if" - it negates its own condition. A bare mura { } with no condition is the else branch. Chain them to get if/else-if/else.

A má chain can be used as an expression only when it ends in a bare mura, so every path produces a value (E507 otherwise); both sides of each branch must agree in type (E201).

There is no ! operator - negate with mura.
